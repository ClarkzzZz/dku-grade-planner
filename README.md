# DKU Grade Planner

COMPSCI 201 三人小组项目：使用 Java 图形界面记录课程成绩，根据 syllabus 中的权重计算成绩，并反推达到目标总分所需的考试成绩。

## 计划功能

- 按类别管理多次 homework、quiz 和考试成绩。
- 支持条目等权平均和总点数汇总。
- 区分未评分和零分，显示类别当前平均与已结束类别贡献。
- 根据目标总分及其他类别的预计最终成绩，反推指定考试需要的百分制成绩。
- 显示目标是否可达、计算假设，以及本地保存和加载。

## 团队计划

详见 [三人分工与开发计划](docs/team-plan.md)。

- A：数据模型与计算逻辑。
- B：GUI 与用户操作。
- C：本地存储、数据校验与整合测试。

A/B/C 待替换为组员姓名。

## 当前状态

仓库已初始化，目前只有规划文档，尚未实现应用。开发环境与启动步骤将在确定 JDK 和 GUI 框架后补充。

第一版针对普通加权评分；不自动解析 syllabus，也不处理额外加分、去掉最低成绩或曲线调整等特殊规则。预测依赖明确填写的其他类别最终成绩假设。
