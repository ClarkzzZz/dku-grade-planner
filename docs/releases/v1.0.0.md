# DKU Grade Planner v1.0.0

First public release of the Java desktop course grade and target exam score planner, following classroom prototypes v0.1–v0.3.

- Create a course with weighted categories and individual homework, quiz, or exam scores.
- Choose equal weighting or total points. Blank scores stay ungraded; zero counts.
- Finalize completed categories and solve one unknown exam using explicit predictions for other unfinished categories.
- See required minimum scores, unreachable targets, and projected overall grades with 0 or 100 on the exam.
- Save and open actual grades as local XML. Target values and predictions are temporary.
- English interface, English/Chinese READMEs, MIT license, and community contribution guidelines.

## Download and run

Install Java 21 or newer and download `dku-grade-planner.jar`, then run:

```sh
java -jar dku-grade-planner.jar
```

A graphical desktop is required. Java is not bundled. `SHA256SUMS` contains the JAR checksum; source code is available through GitHub's source archives.

## Compatibility and limits

Existing XML version 1 files remain compatible. This release supports one course and one unknown exam at a time; dropped scores, extra credit, curves, letter-grade boundaries, mandatory exam pass rules, and syllabus parsing are not supported. Scores are estimates based on the weights and assumptions you enter.

## Validation and known limits

On macOS arm64, all 44 automated checks pass on both Java 21.0.12.1 and Java 25.0.3, including Chinese-default locale runs. Clean-source construction and Java 21 bytecode/package contents have been verified. The [six-job CI matrix](https://github.com/ClarkzzZz/dku-grade-planner/actions/runs/38869378480) passes on Ubuntu, macOS, and Windows with Java 21 and 25. The release tag workflow reruns this matrix before producing its assets.

Full manual GUI acceptance on all platforms remains incomplete. Automated tests cover calculation, model validation, storage, and locale defaults; they do not exercise all Swing interactions or platform file dialogs. Report desktop-specific issues with your OS and Java version. This release does not bundle Java or native installers.

See the [validation record](https://github.com/ClarkzzZz/dku-grade-planner/blob/v1.0.0/docs/validation.md) for exact commands, evidence, and remaining manual checks.
